Version 1.0.0 • No dependencies • 6KB

What It Does

  • Deploys Schema.org JSON-LD markup to your site header
  • Enables remote content publishing via REST API
  • Schema health checks and management dashboard
  • Secure Application Password authentication
  • Works with any WordPress theme
  • No configuration needed — install and activate

How to Install

  1. Download the plugin file above
  2. Go to your WordPress admin → Plugins → Add New → Upload Plugin
  3. Choose the downloaded file and click "Install Now"
  4. Click "Activate"
  5. Go to Users → Profile → scroll to Application Passwords
  6. Enter "AI-Recommendable" and click "Add New Application Password"
  7. Copy the generated password
  8. Send your WordPress URL, username, and the application password to AI-Recommendable
Takes 2 minutes

What Happens After Installation

  1. AI-Recommendable runs a discoverability scan on your site
  2. Schema markup is generated and deployed to your site header
  3. Content improvements are created as draft pages
  4. You review and publish from your WordPress dashboard
  5. Your site is re-scanned in 30 days to track improvement

✅ Secure by Design

The plugin only allows users with edit_theme_options capability to modify schema. Schema markup is stored in your WordPress options table — no files are modified. Your main password is never shared; application passwords are scoped and revocable.
